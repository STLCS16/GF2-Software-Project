# GF2-Software-Project
This project is a Python-based logic simulator developed as GF2.

How to run the simulator

- Open terminal
- Navigate to the `final` folder
- To run command line interface:  
  `python -m logsim.logsim -c definition_files/(name of the file)`
- To run GUI:
  `python -m logsim.logsim definition_files/(name of the file)`
